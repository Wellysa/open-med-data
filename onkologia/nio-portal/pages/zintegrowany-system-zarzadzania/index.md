# Zintegrowany SystemZarządzania
W Narodowym Instytucie Onkologii im. Marii Skłodowskiej-Curie - Państwowym Instytucie Badawczym 
        funkcjonuje i stale jest doskonalony Wewnętrzny System Zarządzania Jakością i Bezpieczeństwem zgodny 
        z wymaganiami Ustawy o jakości w opiece zdrowotnej i bezpieczeństwie pacjenta, norm PN-EN ISO 9001:2015 
        System zarządzania jakością oraz PN-EN ISO 14001:2015 Systemy zarządzania środowiskowego i innymi 
        mającymi zastosowanie, a także standardami akredytacyjnymi. Jednostką certyfikacyjną, która udzieliła 
        rekomendacji i przyznała certyfikaty jest Det Norske Veritas (DNV).
